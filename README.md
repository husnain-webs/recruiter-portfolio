## 🌐 How to Deploy to GitHub Pages

Since your existing repository is hosted at `https://github.com/husnain-webs/husnain-haider-portfolio`:

1. Copy the contents of this folder into your local git repository for `husnain-haider-portfolio`.
2. Commit and push the changes:
   ```bash
   git add .
   git commit -m "feat: complete modern portfolio redesign"
   git push origin main
   ```
3. GitHub Pages will automatically update your live site at:
   **`https://husnain-webs.github.io/husnain-haider-portfolio/`**

## 🛠 Customization

- **Updating Contact Info**: Modify email or phone number in both `index.html` and `js/main.js`.
- **Adding Case Studies**: In `js/main.js`, update the `caseStudiesData` object to add new client achievements, Boolean search strings, or conversion metrics.
- **Adding Your Headshot**: Place your photo into `assets/avatar.jpg` and replace `.avatar-wrapper` in `index.html`.
